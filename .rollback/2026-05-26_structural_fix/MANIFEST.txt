## How to roll back

If L11 misbehaves (e.g. false-positive critical alerts) and you need to
revert just the invariant:

  ssh aaats@100.95.126.39
  cd /home/aaats/aaats
  cp execution/paper_trader.py.bak-<ts> execution/paper_trader.py
  cp trading/live_paper_runner.py.bak-<ts> trading/live_paper_runner.py
  docker compose -f deployment/docker-compose.yml up -d --build --no-deps aaats-paper-crypto

If the autopush expansion is causing problems:

  ssh aaats@100.95.126.39
  sudo cp /home/aaats/bin/aaats-autopush.sh.bak-<ts> /home/aaats/bin/aaats-autopush.sh
  sudo chmod +x /home/aaats/bin/aaats-autopush.sh

To disable the daily digest workflow without redeploying:

  GitHub → Settings → Secrets and variables → Actions → Variables
  Set LIVENESS_ENABLED = false   (this also disables L1 + L7 monitors)
  OR
  GitHub → Actions → AAATS daily digest → ... → Disable workflow
